 # Гостевая книга на Django

## Всякие команды

Зависимости:
```bash
pip install -r requirements.txt
```

Миграции:
```bash
python manage.py makemigrations tasks
python manage.py migrate
```

Запуск:
```bash
python manage.py runserver
```

Создание суперпользователя:
```bash
python manage.py createsuperuser
```

Тесты:
```bash
python -m pytest -v
```
